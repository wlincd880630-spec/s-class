本目录下所有 .png 课件插图（见两个 HTML 中的 media/ 引用）须使用 Google Cloud Vertex AI Imagen 生成。

唯一清单与英文提示词：scripts/imagen-assets.json
可复制提示的页面：vertex-imagen-prompts-open-syllables.html、vertex-imagen-prompts-magic-e.html

生成全部 PNG（需已配置 GOOGLE_CLOUD_PROJECT 并完成 gcloud auth）：
  pip install google-genai pillow
  python scripts/generate_vertex_imagen_assets.py

核对清单与 HTML 引用是否一致（无需 GCP）：
  python scripts/generate_vertex_imagen_assets.py --check-only

请勿用实拍照片或其他非 Imagen 素材替换上述 PNG 文件名，以免与课件风格与版权约定不一致。
