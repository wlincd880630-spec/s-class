语法课程总目录

小学与初中共用同一棵语法树。小学先用声音、图画和句型把语法学会；初中沿同一路径加深规则、对比、转换与中考运用。

知识树：时态 → 名词 / 代词 / 冠词 → 比较 → 情态与句型 → 非谓语入门 → 从句与语态。带「专项 / 入门」的课是主课的加练，不是另一套语法。

  4. P02+ 现在进行时 · 专项 与一般现在时对比；Look! 标志句；句型转换。22–24 页 · 语料加厚 · 对齐初中 04
  5. P03 一般过去时 was/were；规则 -ed；不规则过去式；didn't / Did。对齐初中 05 · 61 页精讲

限定词

非谓语入门

  1. P24 like / enjoy / finish + doing 动名词作宾语；like doing vs want to do。22–24 页 · 语料加厚 · 对齐初中 01

  4. P30 被动语态 · 入门 be + 过去分词；主动变被动；by 执行者。22–24 页 · 语料加厚 · 对齐初中 16
