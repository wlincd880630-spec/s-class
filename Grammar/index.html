小学语法

  1. P1 一般现在时 · 小学版（3–5年级） 声音/图片先行、苏格拉底提问、动作/状态辨析、看图造句、听音排序、DeepSeek 点词。
  2. P2 现在进行时 · 小学版（5–6年级 / 小升初） am/is/are + V-ing、-ing 拼写、now/look 标志词、否定与疑问、状态动词、DeepSeek 语料与配图。
  3. P3 一般过去时 · 小学版（5–6年级 / 小升初） was/were、规则/不规则、-ed 拼写、didn't/Did、听音排序、DeepSeek 语料与配图。
  4. P4 比较级 + than · 小升初真题（Wave 1） 形容词比较级、than 对比、拼写 -er、分类游戏、听音排序、PSLE Set 02 溯源。
  5. P5 最高级 · one of the most（Wave 1） the + 最高级、one of the most + 复数名词、PSLE Set 01 beaches 真题。
  6. P6 名词不规则复数（Wave 1） libraries / children / feet / mice、规则与不规则辨析、PSLE Set 16。
  7. P7 There be 句型（Wave 1） There is/are、就近原则、购物/校园场景、PSLE Set 01 完形。
  8. P8 一般现在时 · 第三人称单数补页（Wave 1） -s/-es、doesn't 否定、PSLE 三单高频考点，衔接 L01 小学版。
  9. P9 一般过去时 · 不规则动词补页（Wave 1） went/bought/thought/saw、动词分组记忆，衔接 L03 小学版。
  10. P10 情态动词 can / should / must（Wave 2） 情态动词 + 动词原形、能力/建议/必须，PSLE 高频 189 处关联。
  11. P11 冠词 a / an / the（Wave 2） 泛指与特指、元音音素用 an、再次提及用 the。
  12. P12 可数与不可数名词（Wave 2） many/few 与 much/little、some/any、计量短语。
  13. P13 祈使句（Wave 2） 动词原形开头、Don't 否定、课堂指令与写作。
  14. P14 一般将来时 will（Wave 2） will + 原形、will be、next week/tomorrow 标志词。
  15. P15 感叹句 What / How（Wave 2） What a/an + 形 + 名、How + 形/副、写作感叹。
  16. P16 too…to / enough to（Wave 2） 太……而不能、足够……可以，完成句子常考。
  17. P17 a few / a little / few / little（Wave 2） 有无 a 意思相反、可数与不可数搭配。
  18. P18 现在进行时 · 小升初补页（Wave 3） am/is/are + V-ing · now/look 标志词 · 与一般现在时对比。
  19. P19 现在完成时 · 入门（Wave 3） have/has + 过去分词 · so far/already/yet 标志词。
  20. P20 被动语态 · 入门（Wave 3） be + 过去分词 · was/were/is/are made · 主被动转换。
  21. P21 宾语从句 · 陈述语序（Wave 3） think/know/say that · 陈述语序 · 连接词 what/if。
  22. P22 like / enjoy / finish + doing（Wave 3） 动名词作宾语 · like doing vs like to do 辨析。
  23. P23 宾格代词 me / him / them（Wave 3） 主格 vs 宾格 · give/tell/help + 宾格 · 写作常错。
  24. P24 some / any / no（Wave 3） 肯定/否定/疑问句搭配 · some or any · no = not any。

初中语法

  1. 01 主谓宾与非谓语 主语、谓语、宾语；谓语与非谓语三种形态，句子成分入门。
  2. 02 主系表与非谓语 主系表结构；系动词、表语与非谓语辨析及搭配巩固。
  3. 03 一般现在时 · 初中版 动作义与状态义动词；be 动词；第三人称单数；否定与疑问。
  4. 04 现在进行时 be + V-ing 构成与用法；标志词；与一般现在时对比。
  5. 05 一般过去时 · 初中版 规则与不规则动词过去式；否定与疑问；时间状语与语篇运用。
  6. 06 名词所有格与 There be 名词所有格、物主代词；there is/are；方位介词。
  7. 07 情态动词 can / must / have to 等；表能力、义务、禁止与许可。
  8. 08 比较级与最高级 比较级与最高级构成；than / as…as；不规则变化；程度副词。
  9. 09 将来时与条件句 will / be going to；零条件句与第一条件句。
  10. 10 过去进行时 was/were + V-ing；与一般过去时连用；听读写综合。
  11. 11 现在完成时 have/has + 过去分词；for/since；与一般过去时对比。
  12. 12 状语从句 时间、条件、原因、结果、目的、让步等状语从句。
  13. 13 宾语从句 that / wh- / if 宾语从句；语序、时态与转述。
  14. 14 定语从句 关系代词 who/whom/which；介词 + which/when/where。
  15. 15 过去完成时 过去的过去；时间锚点；与一般过去时辨析。
  16. 16 被动语态 be + 过去分词；主动↔被动；by；过去/情态被动；made of/from/in。
  17. 17 词性转换与词汇 2018–2026 成都中考全库 699 条：B卷词性转换、Tier2/3、词组搭配习语僻义、图表词、预测补充。
