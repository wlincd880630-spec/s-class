# 课程公共资源

本目录存放**全课程共用**的样式与脚本，供各课 `index.html`、讲义与部分页面通过相对路径引用。

| 文件 | 用途 |
|------|------|
| `grammar-index.css` / `grammar-index-scale.css` | 课程目录页布局与缩放 |
| `grammar-logo.css` | Logo 与品牌样式 |
| `grammar-handout*.css` / `grammar-handout.js` | 背诵/课堂讲义外壳与打印 |
| `grammar-lesson-pager.css` | 讲义翻页条（部分页面） |

各课互动课件的主要脚本在对应 `Lxx/assets/` 下，**不要**删除本目录文件，否则目录页与讲义将无法显示。
