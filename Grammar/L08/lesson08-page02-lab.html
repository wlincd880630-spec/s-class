will 小结

  • will 常表示主观意愿或说话当下对未来的判断与决定。
  • 表将来时，后面可接动词原形（动作），也可接 be（状态、身份、感受等）。骨架与 be going to 类似，只是情态动词换成 will。

will 表将来时，常见两类：后面接动词原形表动作；接 be 表状态。否定常用 will not 或 won't。

一、描述动作

主语 + will + 动词原形 + 其他

肯定句

主语 + will + 动词原形 + …

否定句

主语 + will not / won't + 动词原形 + …

一般疑问句

Will + 主语 + 动词原形 + … ?

特殊疑问句

疑问词 + will + 主语 + 动词原形 + … ?

二、描述状态

主语 + will + be + 其他（形容词 / 名词 / 介词短语等）

肯定句

主语 + will + be + …

否定句

主语 + will not / won't + be + …

一般疑问句

Will + 主语 + be + … ?

特殊疑问句

疑问词 + will + 主语 + be + … ?
