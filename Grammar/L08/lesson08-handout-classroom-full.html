第 1 页

课程导入 · 将来表达全景

课堂流程

  1. 认识三类结构：be going to、will、If…will…。
  2. going to 偏计划与有迹象的推断；will 偏预测、许诺与当场决定。
  3. 第一条件句：真实条件 + 将来结果（主将从现）。

讲义填空

1. be going to 表事先 或近期安排。

2. will 表预测、观点或当场 。

3. If…will… 属于 条件句（第一条件句）。

4. If 从句不用 表将来。

5. 主将从现：从句用一般 时。

6. 主句常用 will + 动词 形。

7. 瞬间动词不宜强行写成 will be ing。

8. 学习路径：分清 going to / will / 条件句。

9. 总结句：本讲三大将来表达各有语义分工；If 从句用现在时表将来，主句用 。

第 2 页

be going to 与 will 概览

课堂流程

  1. be going to：am/is/are + going to + 动词原形。
  2. 有迹象推断：Look at those clouds; it's going to rain.
  3. 对比 will 的预测与当场决定。

讲义填空

1. We are going to plant trees. 结构：be + to + V原形

2. I'm going to take the metro. 口语常缩写为 going to

3. 否定：isn't / aren't to …

4. 一般疑问： you going to join …?

5. Look at those clouds; it's going to .（表迹象推断）

6. going to 偏日程表里已 的安排。

7. will 偏看法、预测或 场表态。

8. Our class is going to give a talk. 表已决定 排。

9. 总结句：be going to = be + going to + 原形；否定/疑问在 上变化。

第 3 页

will + 动词原形

课堂流程

  1. 肯定：S + will + 动词原形；缩写 'll。
  2. 否定：will not / won't。
  3. 疑问：Will + S + V…? 及 Wh- + will 特殊疑问。

讲义填空

1. Clean energy will change the way we travel. will + 动词 形

2. I will send you the poster. 表 诺。

3. 否定：I forget to upload the slides.

4. Will solar roofs become cheaper? 一般疑问把 提前。

5. Yes, I .（肯定简短答语）

6. How will shared power banks change …? 结构：Wh- + + S + V原形

7. The screen will show live crowding. 表 测。

8. won't = will

9. 总结句：will 后接动词 ；否定 won't，疑问 Will 提前，人称不变。

第 4 页

be going to 与 will 辨析

课堂流程

  1. going to：计划、安排、有迹象的推断。
  2. will：预测、许诺、说话瞬间的决定。
  3. 完成对比表并口头举例迁移。

讲义填空

1. 车票已买好 → 常用

2. 说话瞬间决定帮忙 → 常用

3. Don't worry; I will send … 表当场 诺。

4. We're going to upgrade the stations. 表事先 划。

5. Shared bikes will stay popular. 表 测判断。

6. going to 常有证据：车票、聊天、 程表。

7. will 常与 I think / probably 等表 点。

8. 辨析口诀：打算 going to，预测许诺 。

9. 总结句：先判「有无计划/证据」还是「当场决定/观点」，再选 going to 或 。

第 5 页

零条件句与第一条件句

课堂流程

  1. 零条件：If + 一般现在时，主句 + 一般现在时，表客观规律。
  2. 第一条件：If + 一般现在时，主句 + will + V，表真实将来结果。
  3. 对比：规律 vs 可能发生的结果。

讲义填空

1. If you heat ice, it .（零条件主句也用现在时）

2. 零条件描述稳定的客观 律。

3. If the air gets cleaner, families will choose … 第一条件主句用

4. If 从句误用 will → 改用一般 时。

5. ✗ If we will build → ✓ If we

6. 第一条件句谈 实可能的结果。

7. If volunteers keep visiting, trust will .（表将来结果）

8. 零条件 vs 第一条件：现在+现在 vs 现在+

9. 总结句：主将从现——主句 will，从句 用 will；零条件两句皆用现在时。

第 6 页

第一条件句运用

课堂流程

  1. 链式造句：条件 + 结果，话题贴近城市与校园。
  2. 练习 If…, …will… 句型变式。
  3. 口头表达：「若……就会……」。

讲义填空

1. If students learn coding earlier, they will problems.

2. If litter bins are easy to find, the plaza will stay .

3. If we leave earlier, we will catch the train. 条件与结果用 号分隔。

4. If rivers stay protected, birds will to the banks.

5. If each member speaks honestly, the debate will stay .

6. If parents don't sign the form, students won't the trip.

7. 从句否定：If it rain …（不用 will not）

8. Will the park stay open if …? 疑问焦点常在主句 。

9. 总结句：第一条件句 = If + 现在时, 主语 + will + 原形；从句表条件，主句表 来结果。

第 7 页

易错点辨析

课堂流程

  1. 陷阱题：If 从句中的 will、进行时误用。
  2. 时间状语从句（when/before/after）同样主将从现。
  3. 核对口诀自测清单。

讲义填空

1. ✗ If it will rain → ✓ If it

2. ✗ If it will not rain → ✓ If it rain

3. When I will arrive → When I （时间从句同理）

4. If 从句表将来仍用 在时。

5. 主句可用 won't： + S + won't + V原形

6. going to 否定：are going to …

7. 瞬间动词 arrive 不宜写 will be ing

8. ✗ They will going to … → ✓ They going to …

9. 总结句：看到 If/When 先想从句 态；will 与 going to 不可叠用（will going to）。

第 8 页

口语综合练习

课堂流程

  1. 迷你段落：going to + will + If 三句组合。
  2. 话题：出行、校园、社区。
  3. 同伴互听，检查主将从现。

讲义填空

1. Tomorrow we are going to meet at the metro 入口。

2. Smart screens will guide us to less crowded 。

3. If we leave earlier, we will catch the 。

4. Our group is going to test a solar 模型。

5. If clouds cover the sun, the numbers will 。

6. After dinner we are going to walk to the green 。

7. 综括段顺序：going to（计划）→ （预测）→ If（条件结果）。

8. AI tools will help us check 语法。

9. 总结句：口语一段应含 going to、will、If…will… 三种 构，并自查 If 从句无 will。

第 9 页

书面表达

课堂流程

  1. 按话题写 5–8 句：交通、环保、校园或社区。
  2. 至少 1 句 going to、1 句 will、1 句 If…will…。
  3. 结尾用观点句收束，完成写作自检。

讲义填空 · 收官输出

1. The city is going to add more electric 。

2. Fewer petrol cars will mean lighter near schools。

3. If rivers stay protected, birds will return 。

4. We are going to finish the poster 今晚。

5. A greener Chengdu is not going to arrive in one 。

6. Every small choice will 有意义。

7. 书面末句：If young people keep …, our city will …

8. 写作自检：If 从句无 。

9. 总结句：本讲写作核心 = 计划（going to）+ 预测（will）+ 条件结果（If…will…）；中考最忌 If 从句用 。

以下为本讲背诵与拓展附录 · going to · will · 条件句 · 问句 · 写作句 · 口诀

① 将来表达全景：三类核心结构

be going to事先打算 · 近期安排
will预测判断 · 观点/许诺
If..., ...will...第一条件句 · 条件与结果

学习路径：读全景导图分清 going to / will / If → 按模块背诵例句 → 模仿综括段写 3 句组合句 → 对照口诀自测。

易错提醒：在 If 引导的条件状语从句里不用将来时 will（主将从现：从句用一般现在时表将来）；瞬间动词不宜强行写成进行时。

② be going to：事先计划与近期打算

句式结构（肯定 · 否定 · 一般疑问 · 特殊疑问）

句式结构
肯定句S + am / is / are + going to + V原形 · 口语常见缩写 I'm / we're / they're going to …
否定句S + am / is / are + not + going to + V原形 · 常缩写 isn't / aren't / I'm not going to …
一般疑问句Am / Is / Are + S + going to + V …? → Yes, 主语 + am/is/are. / No, 主语 + am/is/are + not.
特殊疑问句疑问词（What / When / Where / Who / Which / How / Why）+ am / is / are + S + going to + V …?
功能提示
已决定安排常有证据：车票、聊天、课程表
迹象推断Look at those clouds; it's going to rain.（现象→将要）

例句积累 · 英汉对照

We are going to plant trees along the river this Saturday morning.

我们打算本周六上午沿河植树。（环保志愿）

I'm going to take the metro Line 18 and then walk to the museum.

我打算乘 18 号线再步行到博物馆。（成都出行）

Our class is going to give a short talk about smart traffic next Monday.

我们班下周一要做一则智慧交通小演讲。（校园任务）

They're going to upgrade the charging stations near our school gate.

他们打算升级校门口的充电桩。（科技基建）

③ will：预测、许诺与即时决定

句式结构（肯定 · 否定 · 一般疑问 · 特殊疑问）

句式结构
肯定句S + will + V原形 · 口语常缩写 'll（I'll / we'll / he'll / they'll …）
否定句S + will not / won't + V原形
一般疑问句Will + S + V …? → Yes, 主语 + will. / No, 主语 + won't.
特殊疑问句疑问词（What / When / Where / Who / Which / How / Why）+ will + S + V …?
辨析：will 偏「看法／预测／当场表态」；be going to 偏「日程表里已定」。二者可在综括文中共存。

例句积累 · 英汉对照

Clean energy will change the way we travel in Chengdu by 2050.

到 2050 年，清洁能源将改变我们在成都的出行方式。（宏观预测）

Shared bikes will stay popular if bike lanes become safer.

若非机动车道更安全，共享单车会一直受欢迎。（预测+条件伏笔）

Don't worry; I will send you the poster before 9 pm.

别担心，我会在晚上 9 点前把海报发给你。（许诺）

The digital screen will show live crowding on each metro car.

电子屏将显示每节车厢的拥挤度。（智慧交通）

④ If 引导的第一条件句：真实条件与将来结果

If + 主语 + 一般现在时（从句）, 主语 + will + V（主句）· 逗号常出现在中间
✗ If it will rain…（从句误用 will）→ ✓ If it rains…  |  ✗ If we will build… → ✓ If we build…

例句积累 · 英汉对照

If the air gets cleaner, more families will choose weekend rides along the greenway.

若空气更洁净，更多家庭会选择周末沿绿道骑行。

If students learn coding earlier, they will solve community problems more creatively.

若学生更早学编程，他们将更有创意地解决社区问题。

If volunteers keep visiting elders, trust between generations will grow.

若志愿者坚持探访长者，代际信任会加深。

If litter bins are easy to find, the plaza will stay tidy with fewer reminders.

若垃圾桶伸手可及，广场只需较少提醒也能保持整洁。

⑤ 否定句、一般疑问句与特殊疑问句

规律：变否定在助动词后加 not（going to 用 be + not；will 用 will not / won't）；变疑问把 be / Will 提前。If 条件句里仍用一般现在时表将来，疑问焦点常在主句的 will。

A · be going to

句式结构骨架
否定句S + am/is/are + not + going to + V原形（口语常见 isn't / aren't / I'm not）
一般疑问句Am / Is / Are + S + going to + V …? → Yes, … / No, …
特殊疑问句疑问词（What / When / Where / Who / How / Why）+ am/is/are + S + going to + V …?

例句积累 · 英汉对照

We are not going to waste paper on one‑time posters.

我们不打算把纸浪费在一次性海报上。（否定）

The team isn't going to cancel the clean-up unless it rains heavily.

除非下大雨，队伍不打算取消清理活动。（否定）

Are you going to join the river patrol this Sunday? Yes, I am. / No, I'm not.

你打算本周日参加河流巡查吗？答：是的 / 不。（一般疑问 + 肯否答语）

Is your class going to host the English corner next Friday?

你们班打算下周五承办英语角吗？（一般疑问）

What are you going to prepare for the "Life in 2050" talk?

你打算为「2050 生活」演讲准备什么？（特殊疑问 · What）

When are they going to repair the lift at the community centre?

他们打算何时修好社区活动中心的电梯？（特殊疑问 · When）

B · will

句式结构骨架
否定句S + will not / won't + V原形
一般疑问句Will + S + V …? → Yes, S will. / No, S won't.
特殊疑问句疑问词 + will + S + V …?

例句积累 · 英汉对照

Air pollution won't disappear in one week, but greener habits will help.

空气污染不会在一周内消失，但更环保的习惯会有帮助。（否定）

I won't forget to upload the slides before class.

我不会忘了课前上传幻灯片。（否定 · 许诺）

Will solar roofs become cheaper by 2035? I think they will.

到 2035 年太阳能屋顶会变便宜吗？我想会的。（一般疑问）

Will your cousin help design the recycling poster?

你表哥会帮忙设计回收海报吗？（一般疑问）

How will shared power banks change evening life in downtown blocks?

共享充电宝会如何改变市中心街区的夜生活？（特殊疑问 · How）

Which station will the express bus reach first after the new ramp opens?

新匝道开通后，快线巴士会先到哪一站？（特殊疑问 · Which）

C · If 第一条件句里的否定与提问

句式结构骨架
否定（从句或主句）If + S + do/does + not + V …, … / If …, S + won't + V …
一般疑问（焦点在主句将来）Will + S + V … + if + S + 一般现在时 …?
特殊疑问疑问词 + will + S + V … + if …? / What will happen if …?
条件从句里仍用一般现在时：✗ If it will not rain → ✓ If it doesn't rain…

例句积累 · 英汉对照

If the alarm doesn't ring, I won't miss the forum; I will still check my watch.

若闹钟不响，我也不会错过论坛；我还会看手表。（从句否定 + 主句否定）

If parents don't sign the form, students won't join the field trip.

若家长不签字，学生就不能参加研学。（条件否定）

Will the park stay open if a yellow wind warning appears?

若发布大风黄色预警，公园还会开放吗？（一般疑问 · If）

Will you still cycle if the winter rain gets heavier?

若冬雨变大，你还会骑车吗？（一般疑问）

What will you prepare if the science teacher asks for an evening presentation?

若科学老师要求做一场晚间展示，你会准备什么？（特殊疑问 · What）

How will volunteers stay safe if the river rises suddenly tonight?

若今夜河水突然上涨，志愿者如何保证安全？（特殊疑问 · How）

⑥ 三类结构综合：迷你段落仿写

范文骨架 A · 清晨出行（going to + will + If）

Tomorrow morning, my friends and I are going to meet at the metro entrance. I believe smart screens will guide us to less crowded cars. If we leave earlier, we will catch the air‑conditioned train without rushing.

明早与朋友约在地铁口见面（going to）；相信智慧屏将指引人少的车厢（will）；若更早出门就能从容赶上空调车（If）。

范文骨架 B · 白日校园

Our science group is going to test a solar model on the playground. The data will probably peak at noon. If clouds cover the sun, the numbers will drop, but we will still record everything carefully.

科学组打算在操场测太阳能模型（going to）；数据可能在正午最高（will）；若云层遮住太阳数值会下降，但仍会认真记录（If）。

范文骨架 C · 傍晚社区

After dinner, my family is going to walk to the green plaza. Neighbours say the lights will look softer after the upgrade. If everyone sorts rubbish correctly, the square will smell fresher every summer night.

晚饭后全家打算散步去绿色小广场（going to）；邻居说灯光升级后会柔和（will）；若垃圾分类到位，夏夜广场会更清新（If）。

观点收尾 · 适用于书面末句

易错提醒：If 从句不用 will（✗ If it will rain）→ 用一般现在时（✓ If it rains）；时间状语从句同理遵循「主将从现」。

背诵口诀 · 核心收束

打算用 going to，预测许诺用 will；
If 从句现在时，主句 will 表将来；
否定 not 在 be / will 后，疑问 be / Will 提前；
going to 有计划，will 当场定；二者可同段，逻辑要分清。
