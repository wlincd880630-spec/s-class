第 1 页

课程导入 · 将来表达全景

课堂流程

  1. 认识三类结构：be going to、will、If…will…。
  2. going to 偏计划；will 偏预测与许诺。
  3. 第一条件句：真实条件 + 将来结果。

讲义填空

1. be going to 表事先 或近期安排

2. will 表预测、观点或

3. If…will… 属于 条件句

4. If 从句不用 表将来

5. 主将从现：从句用一般 时

6. 主句常用 will + 动词 形

7. 瞬间动词不宜强行写成 进行时

8. 学习路径：分清 going to / will /

9. 易错：✗ If it will rain → ✓ If it

第 2 页

be going to 与 will 概览

课堂流程

  1. be going to：am/is/are + going to + V原形。
  2. 已有证据：Look at those clouds; it's going to rain.
  3. 对比 will 的预测与当场决定。

讲义填空

1. We are going to plant trees. 结构：be + to + V

2. I'm going to take the metro. 口语常缩写 going to

3. 否定：isn't / aren't to …

4. 一般疑问： you going to join …?

5. Look at those clouds; it's going to 表迹象推断

6. going to 偏日程表里已 的安排

7. will 偏看法、预测或 场表态

8. Our class is going to give a talk. 表已决定 排

9. 二者可在同一段落 存

第 3 页

will + 动词原形

课堂流程

  1. 肯定：S + will + V原形；缩写 'll。
  2. 否定：will not / won't。
  3. 疑问：Will + S + V…?

讲义填空

1. Clean energy will change the way we travel. will + 形

2. I will send you the poster. 表 诺

3. 否定：I forget to upload the slides.

4. Will solar roofs become cheaper? 一般疑问把 提前

5. Yes, I 肯答 will 句

6. How will shared power banks change …? 特殊疑问词 + + S

7. The screen will show live crowding. 表 测

8. won't = will

9. 口语 I'll / we'll 中 'll 是 写

第 4 页

be going to 与 will 辨析

课堂流程

  1. going to：计划、安排、有迹象的推断。
  2. will：预测、许诺、说话瞬间的决定。
  3. 完成对比表并口头举例。

讲义填空

1. 车票已买好 → 常用

2. 说话瞬间决定帮忙 → 常用

3. Don't worry; I will send … 表当场 诺

4. We're going to upgrade the stations. 表事先 划

5. Shared bikes will stay popular. 表 测判断

6. going to 常有证据：车票、聊天、 程表

7. will 常与 I think / probably 等表 点

8. 辨析口诀：打算 going to，预测许诺

9. 同一段可写 going to + will + 条件句

第 5 页

零条件句与第一条件句

课堂流程

  1. 零条件：If + 一般现在时，主句 + 一般现在时，表规律。
  2. 第一条件：If + 一般现在时，主句 + will + V，表真实将来。
  3. 对比：规律 vs 可能发生的结果。

讲义填空

1. If you heat ice, it 零条件主句也用现在时

2. 零条件描述稳定的 律

3. If the air gets cleaner, families will choose … 第一条件主句用

4. If 从句误用 will → 改用一般 时

5. ✗ If we will build → ✓ If we

6. 第一条件句谈 实可能的结果

7. If volunteers keep visiting, trust will 表将来结果

8. 零条件 vs 第一条件：现在+现在 vs 现在+

9. 主将从现：主句 will，从句 用 will

第 6 页

第一条件句运用

课堂流程

  1. 链式造句：条件 + 结果，话题贴近城市与校园。
  2. 练习 If…, …will… 与 unless 等扩展。
  3. 口头表达：若……就会……。

讲义填空

1. If students learn coding earlier, they will problems.

2. If litter bins are easy to find, the plaza will stay

3. If we leave earlier, we will catch the train. 条件与结果用 号分隔

4. If rivers stay protected, birds will to the banks.

5. If each member speaks honestly, the debate will stay

6. If parents don't sign the form, students won't the trip.

7. 从句否定：If it rain … 不用 will not

8. Will the park stay open if …? 疑问焦点常在主句

9. What will you prepare if …? 特殊疑问 + will + 主句 + 从句

第 7 页

易错点辨析

课堂流程

  1. 陷阱题：If 从句中的 will、进行时误用。
  2. 时间状语从句同样主将从现。
  3. 核对口诀自测清单。

讲义填空

1. ✗ If it will rain → ✓ If it

2. ✗ If it will not rain → ✓ If it rain

3. When I will arrive 应改为 When I 时间从句同理

4. If 从句表将来仍用 在时

5. 主句可用 won't： + S + won't + V

6. going to 否定：are going to …

7. 瞬间动词 arrive 不宜写 will be ing

8. 易错核心：If 从句不用

9. 自测：看到 If 先想从句 态

第 8 页

口语综合练习

课堂流程

  1. 迷你段落：going to + will + If 三句组合。
  2. 话题：出行、校园、社区。
  3. 同伴互听，检查主将从现。

讲义填空

1. Tomorrow we are going to meet at the metro 入口

2. Smart screens will guide us to less crowded

3. If we leave earlier, we will catch the

4. Our group is going to test a solar 模型

5. If clouds cover the sun, the numbers will

6. After dinner we are going to walk to the green

7. 综括段顺序：going to → → If

8. AI tools will help us check 语法

9. 口语目标：一段含三种 构

第 9 页

书面表达

课堂流程

  1. 按话题写 5–8 句：交通、环保、校园或社区。
  2. 至少 1 句 going to、1 句 will、1 句 If…will…。
  3. 结尾用观点句收束。

讲义填空

1. The city is going to add more electric

2. Fewer petrol cars will mean lighter near schools

3. If rivers stay protected, birds will return

4. We are going to finish the poster 今晚

5. A greener Chengdu is not going to arrive in one

6. every small choice will 有意义

7. 书面末句可用 If young people keep …, our city will …

8. 写作自检：If 从句无

9. 本讲写作核心：计划 + 预测 + 件结果
