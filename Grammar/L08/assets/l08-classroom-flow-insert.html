第 1 页

课程导入 · 将来表达全景

课堂流程

  1. 认识三类结构：be going to、will、If…will…。
  2. going to 偏计划与有迹象的推断；will 偏预测、许诺与当场决定。
  3. 第一条件句：真实条件 + 将来结果（主将从现）。

讲义填空

1. be going to 表事先 或近期安排。

2. will 表预测、观点或当场 。

3. If…will… 属于 条件句（第一条件句）。

4. If 从句不用 表将来。

5. 主将从现：从句用一般 时。

6. 主句常用 will + 动词 形。

7. 瞬间动词不宜强行写成 will be ing。

8. 学习路径：分清 going to / will / 条件句。

9. 总结句：本讲三大将来表达各有语义分工；If 从句用现在时表将来，主句用 。

第 2 页

be going to 与 will 概览

课堂流程

  1. be going to：am/is/are + going to + 动词原形。
  2. 有迹象推断：Look at those clouds; it's going to rain.
  3. 对比 will 的预测与当场决定。

讲义填空

1. We are going to plant trees. 结构：be + to + V原形

2. I'm going to take the metro. 口语常缩写为 going to

3. 否定：isn't / aren't to …

4. 一般疑问： you going to join …?

5. Look at those clouds; it's going to .（表迹象推断）

6. going to 偏日程表里已 的安排。

7. will 偏看法、预测或 场表态。

8. Our class is going to give a talk. 表已决定 排。

9. 总结句：be going to = be + going to + 原形；否定/疑问在 上变化。

第 3 页

will + 动词原形

课堂流程

  1. 肯定：S + will + 动词原形；缩写 'll。
  2. 否定：will not / won't。
  3. 疑问：Will + S + V…? 及 Wh- + will 特殊疑问。

讲义填空

1. Clean energy will change the way we travel. will + 动词 形

2. I will send you the poster. 表 诺。

3. 否定：I forget to upload the slides.

4. Will solar roofs become cheaper? 一般疑问把 提前。

5. Yes, I .（肯定简短答语）

6. How will shared power banks change …? 结构：Wh- + + S + V原形

7. The screen will show live crowding. 表 测。

8. won't = will

9. 总结句：will 后接动词 ；否定 won't，疑问 Will 提前，人称不变。

第 4 页

be going to 与 will 辨析

课堂流程

  1. going to：计划、安排、有迹象的推断。
  2. will：预测、许诺、说话瞬间的决定。
  3. 完成对比表并口头举例迁移。

讲义填空

1. 车票已买好 → 常用

2. 说话瞬间决定帮忙 → 常用

3. Don't worry; I will send … 表当场 诺。

4. We're going to upgrade the stations. 表事先 划。

5. Shared bikes will stay popular. 表 测判断。

6. going to 常有证据：车票、聊天、 程表。

7. will 常与 I think / probably 等表 点。

8. 辨析口诀：打算 going to，预测许诺 。

9. 总结句：先判「有无计划/证据」还是「当场决定/观点」，再选 going to 或 。

第 5 页

零条件句与第一条件句

课堂流程

  1. 零条件：If + 一般现在时，主句 + 一般现在时，表客观规律。
  2. 第一条件：If + 一般现在时，主句 + will + V，表真实将来结果。
  3. 对比：规律 vs 可能发生的结果。

讲义填空

1. If you heat ice, it .（零条件主句也用现在时）

2. 零条件描述稳定的客观 律。

3. If the air gets cleaner, families will choose … 第一条件主句用

4. If 从句误用 will → 改用一般 时。

5. ✗ If we will build → ✓ If we

6. 第一条件句谈 实可能的结果。

7. If volunteers keep visiting, trust will .（表将来结果）

8. 零条件 vs 第一条件：现在+现在 vs 现在+

9. 总结句：主将从现——主句 will，从句 用 will；零条件两句皆用现在时。

第 6 页

第一条件句运用

课堂流程

  1. 链式造句：条件 + 结果，话题贴近城市与校园。
  2. 练习 If…, …will… 句型变式。
  3. 口头表达：「若……就会……」。

讲义填空

1. If students learn coding earlier, they will problems.

2. If litter bins are easy to find, the plaza will stay .

3. If we leave earlier, we will catch the train. 条件与结果用 号分隔。

4. If rivers stay protected, birds will to the banks.

5. If each member speaks honestly, the debate will stay .

6. If parents don't sign the form, students won't the trip.

7. 从句否定：If it rain …（不用 will not）

8. Will the park stay open if …? 疑问焦点常在主句 。

9. 总结句：第一条件句 = If + 现在时, 主语 + will + 原形；从句表条件，主句表 来结果。

第 7 页

易错点辨析

课堂流程

  1. 陷阱题：If 从句中的 will、进行时误用。
  2. 时间状语从句（when/before/after）同样主将从现。
  3. 核对口诀自测清单。

讲义填空

1. ✗ If it will rain → ✓ If it

2. ✗ If it will not rain → ✓ If it rain

3. When I will arrive → When I （时间从句同理）

4. If 从句表将来仍用 在时。

5. 主句可用 won't： + S + won't + V原形

6. going to 否定：are going to …

7. 瞬间动词 arrive 不宜写 will be ing

8. ✗ They will going to … → ✓ They going to …

9. 总结句：看到 If/When 先想从句 态；will 与 going to 不可叠用（will going to）。

第 8 页

课堂流程

  2. 话题：出行、校园、社区。
  3. 同伴互听，检查主将从现。

讲义填空

3. If we leave earlier, we will catch the 。

7. 综括段顺序：going to（计划）→ （预测）→ If（条件结果）。

9. 总结句：口语一段应含 going to、will、If…will… 三种 构，并自查 If 从句无 will。

第 9 页

书面表达

课堂流程

  1. 按话题写 5–8 句：交通、环保、校园或社区。
  2. 至少 1 句 going to、1 句 will、1 句 If…will…。
  3. 结尾用观点句收束，完成写作自检。

9. 总结句：本讲写作核心 = 计划（going to）+ 预测（will）+ 条件结果（If…will…）；中考最忌 If 从句用 。
