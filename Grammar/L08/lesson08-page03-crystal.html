中考拓展 · 教材衔接（7–9 年级）

成都英语中考书面表达与填空题中，一般将来时常与科技环保校园生活话题结合。 与本页三句预言对应的教材脉络可参考：七年级「日常活动 / chores」、八年级「未来生活 / robots / environment」、九年级总复习「社会与生活变化」。

一、核心考点（与 Page 01–02 连贯）

  • will 表主观推测（无确凿证据）：In 2050, robots will help us at home.
  • 情态动词后只能接动词原形：拒绝 will doing / will does / will to do（中考阅卷最常见的三类笔误）。
  • 与 be going to 的差异已在 Page 02 情景对比中演练；本页专攻「原形陷阱」。

二、成都中考命题情境（典型方向）

  • 文明城市 / 公园城市：谈论未来交通、绿道、低碳生活 → 常用 will / be going to 描述愿景。
  • 天府文化与科技：博物馆云游览、AI 助教、线上学习 → 动词常为 study / live / use / help 等原形。
  • 校园规则与志愿活动：书面表达常用「I will…」「We will…」表承诺与计划（注意与人称一致的原形，而非第三人称 -s）。

三、应试口诀

  • 「看到 will，后面跟着裸动词；加了 -ing / -es，水晶球必裂！」
