我们对于过去发生的动作用什么时态？对于未来计划中的动作，常用什么结构？它在句子里常长什么样子？

时态小结

  • 我们描述过去在某个时间发生的一次动作，用一般过去时。
  • 我们描述计划好的在未来发生的事情，用一般将来时。

be going to 表打算时，常见两类：后面接动词原形表动作；接be 表状态（身份、性质、感受等）。两类句式骨架相同，中间一节分别是「动词原形」或「be」。

一、描述动作

主语 + am / is / are + going to + 动词原形 + 其他

肯定句

主语 + am / is / are + going to + 动词原形 + …

否定句

主语 + am not / isn't / aren't + going to + 动词原形 + …

一般疑问句

Am / Is / Are + 主语 + going to + 动词原形 + … ?

特殊疑问句

疑问词 + am / is / are + 主语 + going to + 动词原形 + … ?

二、描述状态

主语 + am / is / are + going to + be + 其他（形容词 / 名词 / 介词短语等）

肯定句

主语 + am / is / are + going to + be + …

否定句

主语 + am not / isn't / aren't + going to + be + …

一般疑问句

Am / Is / Are + 主语 + going to + be + … ?

特殊疑问句

疑问词 + am / is / are + 主语 + going to + be + … ?
