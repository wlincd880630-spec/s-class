零条件句（0 号句）· If + 一般现在时，主句 + 一般现在时

普遍规律 用来陈述在时间长河中反复成立的「条件 → 结果」关系：既可以是自然科学里的恒常因果，也可以是日常里的固定程序或习惯联动。 句中的现在时不锚定某一天，而是表示「每当条件出现，结果就随之出现」。

If the wind blows, trees move.

为什么用「九宫格时间线」理解它？

下面九个格子代表不同的日期与天气。零条件句描述的因果关系应当在所有这些情境下都成立——它讲的是稳定的规律，而不是「只针对某一个格子里的那次将来」。

示意：无论哪一天、何种天气，风吹树摇这条规律不变。（教学中可把例句写在九宫格下方，带领学生逐格追问：这一天成立吗？那一天呢？）

小结：零条件句适合描述长期以往、跨时间重复验证的因果链：表格里每一格只是「抽样日期」，真正的语义指向是规律本身，而非某一格里的一次性预测。

三个典型场景（各一句）

  • If the wind blows, trees move. 自然现象：风作为条件，树动作为结果——任意季节、任意一日，只要条件满足，结果随之发生。
  • If you heat ice to 0°C, it melts. 科学真理：条件（加热到熔点）与结果（融化）在实验与生活中可重复验证。
  • If you press the red button, the door opens. 固定程序：电梯、门禁等——每次按下，门就开；描述的是设备逻辑，不是「明天这一次会不会开」的猜测。

第一条件句（1 号句）· 主将从现：If + 一般现在时，主句 + will + 动词原形

可能发生 谈的是某个具体情境下「若条件成立，则将来（或随之）会出现的结果」。中考卷上的「主将从现」指的就是这一条：If 从句不用 will，把「将来」留给主句的 will。

注意：英语里条件句很少写成「If 从句用一般将来时」；即便语义谈将来，If 后也多用一般现在时表条件。

If it rains tomorrow, I will stay at home.

三个典型场景（各一句）

  • If it rains tomorrow, I will stay at home. 天气与计划：明天是否下雨还不确定；下雨 → 我会待在家（针对这一次明天的结果）。
  • If you study hard this term, you will feel more confident. 学业结果：努力发生在接下来这段时间，自信是随之可能出现的变化，强调「这一阶段的如果……就会……」。
  • If he misses the last bus, he will call a taxi. 出行应急：错过末班车是假设的一次事件，打车是对该假设的应对方案（非自然规律）。

与零条件句的对照（一句话）

  • 零条件：谈「总是 / 通常」成立的规律 → 从句、主句都用一般现在时。
  • 第一条件：谈「这一次 / 若果真如此」的后果 → If 从现，主句 will。

下落拦截 · 0 号 vs 1 号条件句

判断长期规律（零条件 · 从现主现）还是当下一次性因果（第一条件 · 主将从现），在句子触底前选对类型以「消灭」该句。共 15 句。

成都中考 · 教材衔接 · 第一条件句（主将从现）

人教版《Go for it》七至九年级在「天气、旅行、聚会计划、环保、规则与安全」等话题中多次出现 If + 一般现在时、主句 will / won't + 原形。 下方按册汇总教材与配套练习里常见的完整第一条件句；最后一栏收录全国各地中考与权威备考资料中反复出现的真题风格完整句（含四川卷常见考法）。

核心规则（与 Page 04 连贯）
  • 主将从现：谈可能发生的条件 —— If 从句用现在时，主句谈结果用 will / won't。
  • 错句示例：If it will rain tomorrow, I will stay home. → If it rains tomorrow, I will stay at home.
  • 成都卷单选 / 完成句子高频陷阱：If 从句里误填 will；或主句忘了 will。
