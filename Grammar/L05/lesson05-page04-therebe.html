场景 · 望远 → 戴眼镜（视频）

最开始，小男孩没有戴眼镜，远处细节模糊，他只能把最先看清的那一个事物说出来，于是他说：

There is a big tree.

当他戴上眼镜之后，视觉分辨提高，他又清楚地看到树下还有两个小孩子。他把新看到的信息接在同一句话里，用 and 做并列追加，于是说成：

There is a big tree and two kids.

There be 句中 be 动词单复数：核心机制（规范表述）
  • 一致关系的“锚点”在首次述位：在存在句 There be … 里，谓语动词 be 的形式通常由最靠近 be 的那个名词短语（教学中常称就近名词）的数来决定，也就是先把“首先被报告/首先进入注意焦点”的那个存在物说出来，并用与之匹配的 is / are 建立句法一致。
  • 并列追加不改变已选定的 be：当说话人继续观察到更多并存的事物，用 and 把后续名词短语接在同一分句里作补充列举时，一般不再回头改写已经脱口而出的 be。原因是：在口语推进与信息增量中，be 已在首次述位时与“第一个名词短语”绑定了主谓一致关系；后续并列成分是在同一存在框架下追加“还有别的什么”，而不是重新启动一次新的主谓一致协商。
  • 课堂记忆式归纳（初一）：先说你最先看清、最先要报告的那一个名词短语是单数还是复数，be 就先定下来；后面再看到的，用 and 继续往同一句里加，但通常不把已说出的 is/are 改成另一种形式来“迁就”后面迟到的信息——这也是教材里会出现 There is a pen and two books. 一类句式的结构理据。

🏆 成都中考必考 · There be 就近原则

一页纸小结

  • There is + 单数 / 不可数；There are + 复数。
  • 两项用 and 连接时，若复数更靠近动词，用 are。
  • 拿不准时：想象「磁铁」吸住离它最近的那个名词。
  • 否定：在 is / are 后加 not（常缩写 isn't / aren't）；肯定句里的 some 在否定句中常改为 any（人教 7A U3/U4 Grammar Focus）。
  • 疑问：Is there …? / Are there …? 语调上扬；简略回答 Yes, there is. / No, there isn't. 与 Yes, there are. / No, there aren't.（成都中考高频）。

There is a smart whiteboard and two blackboards. → There are two blackboards and a smart whiteboard.
