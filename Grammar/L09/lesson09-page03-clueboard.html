结构① · While 从句 = 过去进行｜主句 = 一般过去（突变）

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • 划拍：从句用过去进行拖长；主句一过短促落拍。
  • 重读：突变动词略加重；while 轻读带过。
  • 可全班齐读两遍，再小组接龙只读主句或只读从句。

结构② · 主句 = 过去进行｜when 从句 = 一般过去（点事件）

when 后接「突变点」；主句铺背景进行，与教材常见「背景 + 突变」句型同构。

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • 主句背景进行一口气；到 when 微停顿再接短突变。
  • 注意节拍：短动作词组利落收尾。

结构③ · While + 过进｜主句·一过（叙事完形高频）

中考记叙文常见：散步背景 + came across 发现突变。

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • 关键动词短语读清楚；形容词可略重读。
  • 从句末尾逗号后换气，再读主句。

结构④ · 主句·过进 + while + 从句·过进（双线并行）

两条过去进行时并行描写；适合与「环境 + 动作」同框类阅读对照。

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • while 轻读；表「持续」的片段可稍放慢。
  • 两条进行线同拍长音，体会并行。

结构⑤ · While + 双过去进行（厨房线 + 书桌线）

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • 逗号前读完第一条进行线，换气后读第二条进行线。
  • 两条主语不同，注意代词与停顿，避免「粘成一句」。

结构⑥ · When + 点过｜主句 = 过去进行（铃响·仍在讨论）

when 从句短促；主句延续「还在讨论」— 适合与「打断未停」类阅读题对照。

点击短语块，按正确英语语序接入下方长条（可「清空」重来）。

先点按钮听示范并跟读，再点下方区域显示英文对照。
  • when 后短句利落；主句 were still … 拖长体现「未停」。
  • 名词词尾读清，便于听力辨词。
