第 1 页

课程导入 · 背景与突发动作

课堂流程

  1. 时间轴：过去进行时铺背景，一般过去时记突变。
  2. was / were + V-ing 描写过去某时正在延续的动作。
  3. when / while 分工：时刻突变 vs 并行延续。

讲义填空

1. 过去进行时结构：was / were + 。

2. 一般过去时记录突然发生或已 的动作。

3. 常接突发动作或具体时刻。

4. 常接延续动作并行。

5. find out / come across 等多用 过去时（瞬间动词）。

6. 长背景用 was / were ing。

7. 短突变动作用一般 时记录。

8. 叙事围绕「背景线 + 发线」展开。

9. 总结句：过去进行时铺 ，一般过去时记 ——时态分工须清晰。

第 2 页

过去进行时构成

课堂流程

  1. I / he / she / it → was + V-ing；you / we / they → were + V-ing。
  2. 否定：wasn't / weren't + doing；疑问：Was/Were + S + doing?
  3. be 随主语人称/数变化，V-ing 形式不变。

讲义填空

2. We driving home.

3. It raining hard.

4. They still discussing the plan.

5. 否定：I watching TV at 8 pm.

6. 疑问： you doing your homework then?

7. V-ing 由动词 + 构成。

8. he 作主语用 ，不用 were。

9. 总结句：过去进行时 = was/were + ；否定、疑问在 上操作。

以下为本讲背诵与拓展附录 · 概念 · 句型 · when/while · 例句 · 范文 · 口诀

① 概念对照：背景动作与突发动作

核心概念：在过去的时间轴上，was / were + doing 描写正在延续的背景动作；一般过去时记录突然发生或已经完成的动作。when 常接突发动作或具体时刻，while 常接延续动作；find out / come across / realize / hear 表察觉或偶遇时多用一般过去，不宜误套进行时。

学习路径：读概念对照 → 背句型与 when/while 表 → 积累知识卡例句 → 背诵八句范文 → 对照口诀与易错要点自测。

② 核心对照：句型框架

③ when / while：逻辑与搭配

连词从句侧重常见搭配记忆
when 某一时刻或突变发生 过去进行 + when + 一般过去（短动作打断背景）
while 延续动作并行 While + 过去进行, + 主句（另一延续或突变，依语境）

④ 知识卡例句：英汉对照与句法标注

⑤ 看图写话范文：八句连贯叙事

⑥ 易错要点：自检清单

✗ 瞬间动词进行时：was finding out → ✓ found out  |  ✗ when 从句误用进行：when I was seeing the sign（表看见）→ ✓ when I saw …
写作顺序：先铺 1～2 句 was/were doing 背景 → when 引出突变 → while 可写双线并行 → 末句用一般过去收束感受或结果。

背诵口诀 · 核心收束

长背景用 was doing，短动作用 did 记；when 引出关键点，while 描写并行动作。
come across 表偶遇，find out 表获知；叙事围绕时间线，时态分工要清晰。
