§1  课程叙事、认知主线与课堂环节映射
================================================================================

【大概念】过去的时间轴上：「长背景 was/were doing」像监控录像带；「短事件 did」
像快门一瞬间或闪电打断。精确时刻（at 8:00 p.m.）优先用过去进行时表「当时在干什么」。

【与教材衔接】人教八下 Unit 5（自然灾害对话）中 *We were driving home when…* /
*It was raining hard while we were driving…* 须在 §例句库 与 P02/P04 语料中复现精神。

【八页与 45/120 分钟课型映射】
  P01 认知冲突（引入）：昨天 vs 昨晚八点——「图像先行 + 声音先行」打破舒适区。
  P02 教师示范（隐喻）：时间轴「河与闪电」+ when/while 逻辑门。
  P03 学生模仿：线索板连线，专治瞬间动词 + 进行时的母语负迁移。
  P04 学生练习 + 小组竞赛：机房跳线 + 常识悖论检测（反排除法）。
  P05 技能训练：听力双轨剥离（背景音轨 vs 事件点）。
  P06 技能训练：阅读语篇填空 + 瞬间动词「烈焰」反馈（出版级戏剧化但课堂可控）。
  P07 产出：看图写话 + AI 面批（红圈错词坐标技术）。
  P08 总结与物理讲义：知识卡 + DeepSeek 答疑终端 + @media print 黑白卷。

【教学法清单（每页至少落 2 项）】
  □ 声音先行（先听环境/对话再出字）
  □ 图像先行（先出背景插画再出规则）
  □ 隐喻先行（录像带 / 闪电 / 红线）
  □ 范例先行（教材句 + 成都叙事型真题句式精神 + 生活句）
  □ 支架递减（控制性 → 半开放 → 开放）
  □ 即时反馈（音效 + 色温 + AI 苏格拉底短评中文≤80字）

§3  全局工程铁律（S-Class · 拒收条件）
================================================================================
1. 单文件：每页一个 `lesson09-pageNN-*.html`，内联 style/script；禁止外链业务 JS/CSS。
2. 允许的唯一外部库：Anime.js 3.2.2（jsdelivr CDN）。
3. 允许本地相对资源：`./assets/l09-*.png` 背景与连环画（禁止 base64 大图）。
4. 布局：禁止固定 px 画布；用 vmin/vmax/clamp/calc + 16:9 教学画布策略（可复用
   `../assets/lesson-screen-16x9.css` 若项目已有，但单页演示课仍可自包含）。
5. OOM：临时节点、粒子、全息气泡在 anime complete 后必须 remove；raf 须可取消。
6. UI Lock：TTS 播放、DeepSeek 请求、入场长动画期间 `pointer-events:none` 全屏遮罩。
7. 拖拽：禁止 HTML5 原生 drag；用 pointerdown/move/up + 自写碰撞百分比（≥40% 相交）。
8. DeepSeek 返回 JSON 必须 `replace(/```json|```/gi,'').trim()` 再 parse；超时兜底中文提示。

§4  API 与密钥注入（不写死密钥 · 课堂注入）
================================================================================

【约定配置对象（每页脚本顶部）】
  window.L09_CFG = {
    azureKey: "",           // 课前由教师或本地代理注入
    azureRegion: "southeastasia",
    azureTtsEndpoint: "https://{region}.tts.speech.microsoft.com/cognitiveservices/v1",
    deepseekKey: "",
    deepseekEndpoint: "https://api.deepseek.com/v1/chat/completions",
    deepseekModel: "deepseek-chat"
  };

【Azure TTS】
  • SSML：重读精确时间用 <prosody rate="-8%" pitch="+6Hz" volume="loud">…</prosody>
  • 音色建议：男声讲解 en-GB-RyanNeural；女声系统 en-GB-RyanNeural；旁白 en-GB-RyanNeural
  • Blob → URL.createObjectURL → Audio；播放结束 revokeObjectURL。

【DeepSeek】
  • 温度低（0.3–0.5）；系统角色固定为「时空侦探教研员」；输出控制为中文短句或 JSON。
  • 所有用户可见斥责需「对事不对人」，禁止人身侮辱词汇（出版合规）。
