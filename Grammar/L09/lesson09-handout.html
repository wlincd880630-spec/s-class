过去进行时

was/were + V-ing · 与一般过去时连用 · when / while · 写作八句

① 概念对照：背景动作与突发动作

核心概念：在过去的时间轴上，was / were + doing 描写正在延续的背景动作；一般过去时记录突然发生或已经完成的动作。when 常接突发动作或具体时刻，while 常接延续动作；find out / come across / realize / hear 表察觉或偶遇时多用一般过去，不宜误套进行时。

学习路径：读概念对照 → 背句型与 when/while 表 → 积累知识卡例句 → 背诵八句范文 → 对照口诀与易错要点自测。

② 核心对照：句型框架

③ when / while：逻辑与搭配

连词从句侧重常见搭配记忆
when 某一时刻或突变发生 过去进行 + when + 一般过去（短动作打断背景）
while 延续动作并行 While + 过去进行, + 主句（另一延续或突变，依语境）

④ 知识卡例句：英汉对照与句法标注

⑤ 看图写话范文：八句连贯叙事

⑥ 易错要点：自检清单

✗ 瞬间动词进行时：was finding out → ✓ found out  |  ✗ when 从句误用进行：when I was seeing the sign（表看见）→ ✓ when I saw …
写作顺序：先铺 1～2 句 was/were doing 背景 → when 引出突变 → while 可写双线并行 → 末句用一般过去收束感受或结果。

背诵口诀 · 核心收束

长背景用 was doing，短动作用 did 记；when 引出关键点，while 描写并行动作。
come across 表偶遇，find out 表获知；叙事围绕时间线，时态分工要清晰。
