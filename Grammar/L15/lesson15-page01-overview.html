词性转换 · 中考 B 卷核心

定义：同一词根在不同词性间变形，使句子语法正确。

成都中考 B 卷「12 选 10」每年必考；全库 699 条。→ 九年真题词形归类（90 空） · 全库检索

  1. 判定：名词 / 动词 / 形容词 / 副词 / 代词
  2. 技巧：形容词 + -ly → 副词；动词 + -tion/-ment → 名词
  3. 句首评注副词：见第 3–4 屏（Sadly, / Honestly, … + 逗号）
  4. 迁移：they→their；little→less；good→well
