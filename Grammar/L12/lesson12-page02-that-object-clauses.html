宾语从句在说什么？

宾语从句是用一整句从句去充当及物动词（或少数介词后）的宾语。它要替你说清楚的不是「谁 / 什么」，而是： 某人具体说了什么 · 某人具体知道什么 · 某人具体希望什么 · 某人具体相信什么 · 某人具体发现什么 · 某人具体决定了什么 · 某人具体记住了什么 等「打包成一句的信息内容」。

主语 + 观点 / 转述动词 + that（连接） + 陈述语序的从句

教材 / 真题 / 大纲常见「that 宾从」动词族（节选）

言说类 say, tell, explain, announce, suggest（后接 that 从句表「说的内容」）
认知类 know, think, believe, understand, realize, learn, find（发现）, discover
情感 / 意愿 hope, wish（注意语气差异，本课以 hope 为主）, agree, feel
其他高频 hear, see（理解义）, mean, remember, forget, decide, show

场景 ① · 某人具体说了什么（say）

图片先行 · 某人具体说了什么（厨房·妈妈）

小朋友在客厅要向爸爸说明：从妈妈在厨房亲口说的那句话里，具体要转述给爸爸的信息是什么？先把那句英文原话听清楚，再想：怎样用 Mom says + that 把「转述」和「内容」接成一整句，用来表达妈妈具体说了什么。
Mom says …（主语 + 转述动词，话还没说完）
Dinner will be ready in 10 minutes.（妈妈说的具体内容 → 作宾语，要用 that 接到上面）

场景 ② · 某人具体知道什么（know）

图片先行 · 某人具体知道什么（老师转达·图书闭馆）

我们从图书管理员的话中具体知道什么？先把这条英文信息原句听清楚，再想：英语里怎样把 We know 和这个事实用 that 连起来，用来表达我们知道的具体信息。
We know …（认知动词，后面要接「所知道的内容」）

看着窗外的天色，说话人具体希望明天出现怎样的天气结果？先把你听到的那句英文愿望原句听清楚，再想：怎样用 I hope + that 把「愿望」和「希望成真的那件事」接起来，用来表达心里具体盼着的那条信息。
I hope …（表达愿望，后面跟希望成真的事情）

场景 ④ · 某人具体相信什么（believe）

图片先行 · 某人具体相信什么（同伴·鼓励）

听着同伴的鼓励，她具体相信了我的哪一种可能？先把同伴说出口的那句英文原话听清楚，再想：怎样用 She believes + that 把「她的态度」和「她相信我能通过考试」接起来，用来表达她具体相信的内容。
She believes …（主语 she + 第三人称单数 believes）
I can pass the exam.（同伴对你说的原话是 You can pass the exam.；从「我」转述进宾从时 you → I，再用 that 接到 believes 后）

进阶 · 否定转移与反意疑问（think / believe + 宾从）

中文常说「我认为他不……」，英语里更自然的常式常把否定放在主句：I don't think / believe / suppose + (that) + 肯定式从句。

高频语料库

口语 · 委婉否定
  • I don't think that this plan is fair without more discussion.
  • I don't believe that anyone can finish it in one hour.
  • I don't suppose that the train will be on time in this weather.
口语 · 评价人与事
  • I don't think that the new timetable is fair to everyone.
  • We don't think that the result is good enough yet.
  • He doesn't think that the story is true.
写作 · 观点段
  • Personally, I don't think that online learning can fully replace face-to-face classes.
  • Many parents don't believe that students should stay up too late.
写作 · 建议/倡议
  • We don't think that it is a good idea to skip breakfast before PE class.
  • I don't think that we should give up; we can try a different method.
