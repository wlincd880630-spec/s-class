状语从句 —— 课程目标

课程目标

  • ① 结果：so / such + … + that · 写感受「太……以至于……」
  • ② 目的：so that + 从句（常含 can/could/will）· 写打算「为了……」
  • ③ 红线：so 与 so that 之间不插形容词（与 Page 02 的 because/so 不连用不同类）
口诀：结果看「已经」；目的看「为了」——目的从句里常出现 can / could / will。

状语从句 —— 结果 so…that

so + 形容词/副词 + that + 从句（结果）
语义：如此……以至于……。that 后写已经发生的结果，常见 couldn't / fell asleep / canceled 等。

He was so tired that he fell asleep on the sofa.

She spoke so fast that I couldn't follow every word.

状语从句 —— 目的 so that

主句 + so that + 从句（目的，常含 can/could/will）
写计划、学习方法、安全出行时很好用：为了以便……。不要写成 so + 形容词 + that。

I got up early so that I could catch the first bus.

They made a plan so that they wouldn't waste the summer holiday.

状语从句 —— 小结

  • 结果：so + 形/副 + that；名词中心用 such…that；谈「已经怎样」。
  • 目的：so that + 从句（常 can/could/will）；谈「为了能怎样」。
  • too…to：太……而不能……（无 that 从句）· 与 so…that 勿混。
  • 学习顺序：结果 → 目的 → such…that → 对照与辨析。
  • 暑假写作：见下一屏「口语与写作」· 各写 so/such、so that、too…to 各一句。
