状语从句 —— 小结

  • 功能：时间 / 原因 / 条件 / 让步 / 目的 / 结果 —— 先读懂大意再说功能。
  • 条件·原因：if / unless（unless 后不再叠 not）· because / since / as · 禁 because…so。
  • 结果·目的：so…that / such…that · so that（为了）。
  • 让步：although / though · 禁 although…but。
  • 时间·合并：until / not…until / as soon as（从句现、主句将）· 先判关系再选连词。
