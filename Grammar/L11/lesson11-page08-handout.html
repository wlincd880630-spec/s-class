① 六类状语从句 · 功能速记总表

连词是入口，功能才是答案。圈从句时圈完整从句，不只圈连词。自问：这个从句回答的是下面哪一个？

功能常见连词自问例句骨架
时间 when / before / after / until / as soon as 什么时候？持续到何时？一……就……？ As soon as the holiday begins, I will make a plan.
原因 because / since / as 为什么？/ 既然…… I won't stay up late because I want to keep healthy.
条件 if / unless 在什么条件下？/ 除非…… If the weather is fine, I will ride my bike.
让步 although / though / even though 尽管……仍然…… Although the sun was strong, we arrived on time.
目的 so that / in order that 为了……能…… I will put my phone away so that I can focus on reading.
结果 so…that / such…that 如此……以至于……（已发生） The story was so interesting that I finished it in one day.

短语状语（如 in the park）信息少；状语从句自带主谓，能说清「什么时候 / 为什么 / 在什么条件下」等。（Page 01）

② 条件与原因（Page 02）

条件 · if / unless
  • If you ask politely, people are usually willing to help.
  • Unless you hurry, you will be late.（≈ if…not）
  • unless 后不再叠 not：unless you don't finish → unless you finish
  • 主将从现（1 号条件句）：If it rains, I will stay at home.
  • If you heat ice, it melts.（0 号 · 真理）
原因 · because / since / as
  • Because the road was icy, we walked slowly.（直接原因）
  • Since everyone was tired, we stopped early.（既然）
  • As it was getting dark, we turned on the lights.（随着/因为）
  • 语气：because 最强 · since/as 较弱，常放句首。

条件句类型（拓展）

类型结构示例
0 号if + 一般现在，主句一般现在If you heat water to 100°C, it boils.
1 号if + 一般现在，主句 will/情态/祈使If the weather is fine, I will go hiking.
2 号if + 过去式，主句 wouldIf I had more time, I would read more.
3 号if + 过去完成，主句 would have p.p.If I had left earlier, I would have caught the train.

③ 结果与目的 · too…to（Page 03）

结果 · so…that / such…that

已经如此……以至于……（结果已发生）

  • The wind was so strong that we closed the windows.（形/副 + so）
  • It was such a useful lesson that I shared my notes.（名 + such）
  • He was so tired that he fell asleep.（≠ too tired to sleep）
目的 · so that

为了能……；从句常含 can / could / will

  • I saved screenshots so that I could find the way without the Internet.
  • She spoke slowly so that everyone could understand her.
  • 陷阱：opened the window so wide that… → opened the window so that…
too…to（对比，非从句）
  • He was too tired to walk any further.（太……而不能）
  • The box was too heavy to carry alone.
  • 辨析：so…that 有 that 从句；too…to 后接不定式。
结果 vs 目的 · 一句话
  • 结果：谈「已经怎样」→ so…that
  • 目的：谈「为了能怎样」→ so that
  • so 与 so that 之间不插形容词。

④ 让步与不连用（Page 04）

让步 · although / though
  • Although the plan may not be perfect, I will try to follow it.
  • Though it was raining, they kept practising.
  • 提高：Even though I was nervous, I became calmer.
  • 中文「虽然……但是……」→ 英文只留一侧连词。
一层连词 · 不连用
转折 / 因果各选一层：有 although 就别再加 but；有 because 就别再加 so。
  • Although it was late, but I finished.
  • Although it was late, I finished my work.
  • Because it was cold, so I wore a coat.
  • Because it was cold, I wore a coat. / It was cold, so I wore a coat.

⑤ 时间与合并（Page 05）

until

动作持续到某时点

  • Wait here until I come back.
  • We kept working until the bags were full.
not…until

直到……才……

  • I didn't go to bed until I finished my homework.
  • The bus didn't move until the light turned green.
as soon as

一……就…… · 主将从现

  • As soon as I get home, I will call you.
  • 从句不用 will：As soon as I will arrive…

until（时间终点）≠ unless（条件）。until 等到 · unless 除非。

合并句 · 四步法

  1. 读两句 → ② 判关系（时间/条件/让步/目的/结果/原因）→ ③ 选连词 → ④ 合成一句
  2. 例：I get home. + I will call you. → As soon as I get home, I will call you.
  3. 例：He checked the windows. + He left. → He didn't leave until he checked the windows.
  4. 例：It was cold. + We went hiking. → Although it was cold, we went hiking.

⑥ 阅读标注 · 写作句架（Page 06）

语篇三步：① 读懂大意 ② 圈完整从句 ③ 说清功能。写作 80～120 词，至少 3 类状语从句。

写作句架芯片
  • As soon as the summer holiday begins, I will _____.
  • I won't go to bed until I finish _____.
  • If the weather is fine, I will _____.
  • I want to _____ because _____.
  • I will make a plan so that I can _____.
  • Although the plan may be hard, I will _____.
范文要点（My Summer Plan）
  • 开头：As soon as … begins → 列计划
  • 中段：because / If / so that
  • 让步：Although … not perfect, still try
  • 结果（可选）：so … that / such … that

⑦ 实用语料库（口语 · 写作 · 本讲话题）

暑假计划 · 社区环保 · 独自出行 · 健康习惯。建议抄 8～10 句进积累本，写作时替换人名/时间/地点。

口语暑假计划
  • As soon as the holiday begins, I'll make a weekly plan.
  • I won't play games until I finish my homework.
  • I'll put my phone away so that I can focus on reading.
  • Although the plan may not be perfect, I'll try step by step.
口语环保 · 志愿
  • Although the sun was strong, everyone arrived on time.
  • We wore gloves so that we could pick up rubbish safely.
  • Because some kids didn't know how to sort waste, we taught them.
  • As soon as the street looked clean, neighbours thanked us.
写作倡议书 / 计划段
  • We made a plan so that we wouldn't waste the summer holiday.
  • Many students believe that balance between study and rest matters.
  • It is clear that everyone needs a safe environment at school.
独自出行 · 提高（Passage C）
  • Since I had never planned a route, I checked the map twice.
  • I saved screenshots so that I could find the way offline.
  • If I missed a train, I would wait for the next one.
  • It was such a useful trip that I wrote in my diary.
⑧ 易错红线 · 课堂速改（12 条）
  1. As soon as I will get home… → As soon as I get home…
  2. I waited unless he came. → I waited until he came.
  3. Because …, so … → 只留 because 或 so 一侧
  4. Although …, but … → 只留 although
  5. unless … don't … → unless …（肯定式）
  6. 目的 vs 结果：想「为了」→ so that；想「以至于」→ so/such…that
  7. so wide that（表目的）→ so that
  8. until 强调持续；not…until 强调直到才
  9. 只圈连词不圈从句 → 应圈完整从句
  10. 把 Since 标成「时间」→ 此处表原因
  11. 把 until 标成「条件」→ 此处表时间
  12. 写作：as soon as 从句里慎用 will
⑨ 当堂测前 · 自检清单
  1. 能说出六类功能各一句例句。
  2. 会辨 if / unless / until / as soon as。
  3. 会辨 so…that / such…that / so that / too…to。
  4. 见到 because…so、although…but 能改对。
  5. 合并句：先判关系再选连词。
  6. 微语篇：能找 As soon as / because / so that / Although。
  7. 完成当堂测后对照本讲义复盘。

although 后不 but，as soon as 从句现；
until 持续到，not…until 直到才；
