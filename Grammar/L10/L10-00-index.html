Lesson 10

现在完成时（一）（二）· 经验与改变 & 时间的长度

Have you ever…? · for / since · already / yet

本课学习目标

  1. 我能说出并写出现在完成时的基本结构，并区分「影响现在」与「持续到现在」两种核心意义。 I can use have/has + past participle and tell “result now” vs “still continuing”.
  2. 我能正确使用 already, yet, just, ever, never，并完成 Have you ever…? 口头问答。 I can place adverbs and ask / answer about experiences.
  3. 我能用 for / since 与 How long…? 描述时长，并初步辨析现在完成时与一般过去时。 I can use for / since and compare with the past simple.

课前预习

  1. 复习不规则动词过去分词（为 have/has + p.p. 做准备）。
  2. 默读或大声朗读一遍学习目标，并尝试跟读英文句。
不规则动词过去分词（示例 5 个）
  • go → gone
  • see → seen
  • do → done
  • read → read
  • write → written
