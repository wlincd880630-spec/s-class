全课教学目标（教师版汇总）

  1. 结构与读音：have/has + past participle，第三人称用 has；不规则过去分词巩固。
  2. 意义双线：「影响现在的结果」与「从过去持续到现在」；能与一般过去时在时间状语下辨析。
  3. 标志词与搭配：already, yet, just, ever, never；for / since / How long；延续性表达（如 keep, have, be open）。
  4. 产出：口头 Have you ever…?；笔头段落与翻译；阅读微技能与限时测评。

全课易错点档案（与大纲一致 · 讲评可逐条对照）

  1. 把 yesterday / last… / …ago 与 have/has + p.p. 绑在一起 → 应改用一般过去时。
  2. since 后误接「时长段」→ 表段长用 for，since 接时间点或从句。
  3. 瞬间动词（buy, borrow, open 作「动作」义）与 for two weeks 直接连用 → 改为状态类（have, keep, be open）。
  4. 疑问句末 yet 与助动词：常用 Have you… yet? 而非 Do you… yet?
  5. already 位置与语气：多在肯定句中位或末；否定误放 already。
  6. 主谓一致：neither of + 复数名词 谓语常用单数 has/has not。
  7. 经历次数「无具体过去年份」与「钉在过去一年」语域混淆 → 影响现完与一般过去选择。

差异化任务 A / B / C（可复印学案）

A 层 · 学困支架

  • 跟读「主题 A」前两句，圈出 already / yet。
  • 用所给词块造句：I have not … yet. + 词块：finish / homework。
  • 半句翻译：我们自从三月以来________（植树）→ 给中文提示：现在完成时 + since March。
  • 听音勾题：教师朗读 4 句，勾出含 for 的一句。

B 层 · 中等巩固

  • 用 for 写自己的一句真实话（学习或运动时长）。
  • 中译英：「他自从七年级以来一直是志愿者。」
  • 配对：左列时间状语，右列选现完或一般过去。
  • 口头回答 Have you ever…? 并追问一句 When did you…?

C 层 · 学优拓展

  • 合并句：两句用 since 从句连接，保持时态一致。
  • 写两句：一句含 for 段时，一句含 since 从句。
  • 语篇一句复杂现完：描述学校一项「从过去到现在」的变化并给出证据词。
  • 自命题：模仿中考单选，自编 1 题并写解析。

家长会一句话沟通模板（约五百字）
