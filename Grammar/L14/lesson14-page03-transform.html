声先行 · 四步口诀

先听转换步骤，再显示文字：转换不是翻译，而是重排信息焦点

  1. Find the object — it becomes the new subject.
  2. Change the verb to be + past participle.
  3. Add by + agent if needed.
  4. Keep time and place.

找宾语→放句首 · 动词→be+过去分词 · 必要时 by · 保留时间地点

教师提示：先让学生用中文说“主动句宾语是谁”，再动笔改写。若宾语找错，后面的 be 和 V3 都会连锁出错。
