## 一、本对话中你对课件的要求与思路（归纳）

以下整理自 **L13 Page 03～08** 等对话中的明确指令与反复修正，可作为 **L14 及后续各讲的硬约束**。

### 1.1 版式与交互

| 要求 | 具体做法 |
|------|----------|
| **全屏分页** | 每 HTML 内多「屏」`lesson-page` + 底栏 `lesson-pager`；**禁止**一屏塞满多道练习题 |
| **每题一屏** | 填空、快选、测验等：**一次只显示一题**，配进度、圆点、上一题/下一题 |
| **大屏可读** | 独立 `l14-page*-readable-text.css`；投影字号用 `clamp` + 大屏 media query |
| **删除冗余屏** | 小结口诀、同伴互评、重复轮播等可删；通道页保留 |
| **讲义** | 可 **纯文字、无图**；多题材故事范例；打印 A4 单栏 |
| **删除整页** | 按教学需要整节移除（如 L06「顺序词块·拼装复述」） |

### 1.2 教学法（你强调的八项）

| 方法 | L14 落点 |
|------|----------|
| **图片先行** | 先场景图/分镜，再出句子；`panel-split` 左图右文 |
| **声音先行** | 先播环境/对话 TTS，再显示英文；按钮「先听再读」 |
| **苏格拉底提问** | 中文引导问：「谁是动作承受者？」「句子里谁更重要？」不直接给定义 |
| **教师展示** | 屏内 `teacher-note` / 规则盒由教师点开「公布」 |
| **定义后置** | 学生拖拽/排序/判断后再出现 `be + done` 公式 |
| **学生总结** | 屏末「你说说被动语态是什么」+ 芯片填空总结 |
| **分层练习** | **A** 精讲匹配 · **B** 快选/填空 · **C** 翻译/语篇 |
| **错句先显** | 陷阱题先显示 ✗，再「显示正句」 |

### 1.3 内容与语料

| 要求 | 具体做法 |
|------|----------|
| **难度** | 对齐 **人教九年级** Unit 5～7 + **中考**动词形式/语态考点 |
| **语料来源** | 教材 OCR 原句 + 中考阅读改编；标注出处 |
| **主题** | 材质产地、发明史、青少年规则、环保（Unit 13 复现） |
| **先整合再设计** | 初中教材 TXT、成都中考 HTML、教学纲要 HTML → `design-lesson14-corpus.md` |

### 1.4 技术与部署

- `assets/lesson-screen-16x9.css` + 每页 `layout` / `readable-text`
- `index.html` 学习目录；顶栏/底栏链回目录
- 配图 PNG；**禁止 SVG 作主教学图**（L10 规范）
- Azure TTS；可选 DeepSeek 苏格拉底（密钥不入库时用占位）

### 1.5 你的隐含教研思路

1. **先发现、后命名** — 从「茶被种植」等现象归纳，少背定义开头。  
2. **功能重于形式** — 强调「主语是承受者」「施事可省略」。  
3. **一条叙事线** — 工坊探秘：中国制造 → 发明馆 → 规则辩论。  
4. **分层不增负** — A/B/C 标签清晰，B 不重复 A 长篇。  
5. **可打印可测评** — 讲义 + 当堂测，服务 3 小时面授。

## 六、注意事项（上课与制作）

1. **易错**：漏 be；done 用成过去式；情态后仍用 be done（should **be** allowed）。  
2. **不与过去完成时混淆**（L13 已学）：本讲只涉及 **be + pp**，不涉及 had done。  
3. **成都中考 HTML** 无「被动」标注题 → 练习以教材 4a/4c + 纲要真题类型（动词形式）为主。  
4. **TTS / 图片** 需联网或本地 `assets` 完整拷贝方可离线。  
5. **3 小时课** 可拆：第 1 课时 01～04；第 2 课时 05～08；第 3 课时 09～10 + 讲义背诵。
