时间轴 · 三时态被动

过去 was/were → 将来 will be → 完成 have/has been

was / were + done → will be + done → have / has been + done
  • 将来：强调将要被做 · next year / tomorrow
  • 完成：强调已经被做 · already / yet / this year

出版提示：本页只扩展两个新时态。过去被动用于已发生的过去事件；将来被动看未来时间；现在完成被动看“已经/尚未”的结果。
