# Lesson 14 · 被动语态

**场景**：工坊探秘社 · Made & Done Workshop  
**课时**：约 180 分钟（3 小时）  
**语法**：be + 过去分词 · 主动↔被动 · by · 过去被动 · 情态被动 · made of/from/in

**入口**：课程总目录第 16 讲 → `L14/index.html`

## 文件结构

- `index.html` — 学习目录（与全站 `shared/grammar-index.css` 统一样式）
- `lesson14-page01-discovery.html` … `lesson14-page11-handout.html`
- `design-lesson14-overview.md` — 总纲（含你的课件要求归纳 + L01～L13 对照）
- `design-lesson14-pages.md` — 分屏设计稿
- `design-lesson14-corpus.md` — 教材/纲要/中考语料整合
- `assets/lesson-screen-16x9.css` · `assets/img/*.png`
- `l14-lesson-shell.css` · `l14-page-components.css` · `l14-index-nav.*`

## 使用

1. 用浏览器打开 `index.html`
2. 投影课建议全屏；需 Azure TTS 时请联网
3. Page 10 PDF 导出需 CDN `html2pdf.js`（若已接入）
4. Page 11 讲义：打印 → 背景图形 → 另存 PDF
