若仍打不开：① 确认手机与电脑是同一 WiFi（不要用「访客 WiFi」）；② Windows 防火墙放行端口 8765（可右键「以管理员运行」添加防火墙规则-教研端口.bat）。

部署到自己的网站（HTTPS）后，老师能用手机访问并上传吗？

可以。把本页 index.html（及同目录若以后有拆分出的 js/css）放到你的前端静态空间后，把链接发给老师即可，例如 https://你的域名/路径/index.html，上传专用短链为 …/index.html?upload=1，二维码也会按当前域名生成。

但要注意三点：

  • 数据不在你的服务器上：记录存在每位老师自己浏览器的本地存储里，互不相通。教研组长要汇总，仍需各人「导出同步包」发给你再「导入」，或以后加真正的后端/数据库。
  • API 密钥不要写在公网页面里：当前若把密钥写进 HTML，任何人打开网页都能在源代码里看到并盗用。公网部署请删掉内置密钥，只在本机用「保存自定义密钥」；理想做法是你方服务器做一个转发接口，密钥只放在服务器环境变量里。
  • 浏览器直接调 DeepSeek 可能被拦截：部分环境下跨域（CORS）会导致识图接口失败；若部署后识别一直失败，需要在你自己的域名下加一层后端代理再调 DeepSeek。

仅局域网用时：手机与电脑数据不互通。可在电脑上双击运行文件夹里的 启动局域网访问.bat，用手机访问窗口里给出的 http://电脑IP:8765/...（不要用 localhost、不要只靠 file:/// 打开 html）。手机上传后可「导出同步包」到电脑「导入」合并。
