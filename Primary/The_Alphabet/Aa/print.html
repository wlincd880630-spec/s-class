教材作业包 · Student's Book 新彩页

对应教材 A–E：angry apple、四个单词、四线格描 Aa、听音写 Aa 或打叉、chant 小火车。课堂讲义或回家作业都可以打。

  • 封面 + Listen and say + 四个 /æ/ 朋友
  • 描红大 A / 小 a（绿点起笔）
  • Track 05 听音写 Aa 或 X · Track 06 chant 写序号

打印窗口里选「另存为 PDF」，纸张 A4，边距「无」或「默认」，打开「背景图形」才能印出彩底。

练习册 · Workbook 新彩页

对应练习册 A 描红、B 圈 /æ/ 图、C 给 A a 涂色。B 题用野餐贴纸风，C 题用气球，不再使用原书黑白牙齿格。

  • apple 已示范圈好；banana、computer 是干扰项
  • 气球上有 A a c B a C b A，只涂 A 和 a
  • 屏幕上也可以先做一遍：打开「互动练习册」
先在屏幕上做练习册

彩色打印效果最好。学生用蜡笔涂气球、用铅笔写四线格。

六个复习游戏 · 纸上版

和屏幕游戏同一套技能，改成圈图、写序号、打叉、连线、剪卡排队，不需要平板也能复习。

  • 开头音小侦探 · 听音写序号 · 谁是局外人
  • 图词连线 + 剪开做配对 / 翻牌
  • 写 Aa 或打叉 · Chant 剪图排队

四线格抄写 · 勾选单词再导出

每个单词单独一页：先看图，再描红 3 次，最后独立书写 3 次。字是 Patrick Hand 手写体，落在蓝绿红四线格里，适合低龄描摹。

默认勾选 apple / axe / ant / alligator。也可以加上字母 Aa 和 angry apple。

教学教具 · 字母卡、图片卡、单词卡

给老师上课用的实物教具。图片卡正面只有图，单词卡只有词，另外提供对折卡（正面图、背面词），方便图词配对、闪卡、分类和 chant 排队。

  • 全页海报：大 A、小 a、Aa /æ/
  • 对折闪卡：剪开后对折粘好，正面 apple 图、背面 apple
  • 4 开图片卡 + 4 开单词卡，可做实物配对
  • 口袋小卡 ×8（含 banana、computer 等干扰图）
  • /æ/ 火车厢分类垫 + 不是 /æ/ 的篮子

建议彩打在 160g 卡纸上，对折卡可覆膜。低龄班请老师代剪圆角。

课堂怎么玩这些教具

对折闪卡、图词配对、绕教室、听音举卡、苍蝇拍、开头音分类、缺了谁、记忆翻牌、口袋表、字母海报书空、chant 小火车……打印这一本给老师看。
