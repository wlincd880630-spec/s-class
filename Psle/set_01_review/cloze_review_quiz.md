# 第01套 · 词汇语法复习卷（学后测试）

满分 **60 分** · 建议 30–35 分钟 · 可导出纸质 PDF

## 结构

### 基础 · 20分
- A 固定搭配连线（4）
- B 选词填空（4）
- C 形容词 / 副词词性辨析（6）
- D 词形变化（6）

### 提高 · 20分
- A 单项选择（8）——含 **on sale + half price** 唯一答案题
- B 短文填空（8）——**50% off** 锁定 on sale
- C 看图排列句子顺序（4）——三格连图

### 挑战 · 20分
- A 微型完形（8）——half price 锁定 on（排除 for sale 歧义）
- B 看图造句（12）——thirsty / look at / on sale（另有 choose、look for 选做）
