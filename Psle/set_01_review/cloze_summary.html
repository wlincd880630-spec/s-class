3. 核心知识卡片

① 固定搭配

  • shop for sth. 为买……而购物
  • on sale 打折（≠ for sale 待售）
  • pay...for... 为……付款
  • It takes sb. time to do sth.

② 花费四兄弟

  • cost：物 + cost + (人) + 钱
  • spend：人 + spend + 时间/钱 + on/(in) doing
  • pay：人 + pay + 钱 + for
  • take：It takes + 人 + 时间 + to do

③ look 短语

  • look at 看
  • look for 寻找
  • look after 照顾
  • look into 调查

④ 购物 + 情绪

  • size / colour / price / on sale
  • hungry / thirsty / tired / sick
  • afraid / sad / angry / lonely
  • happy → happily（副词）

⑦ 语境线索解题法

  • 前后因果：买了可乐 → 因为口渴
  • 工具线索：拿起笔 → 写规定
  • 情绪线索：走散 → 妈妈害怕
  • 生活常识：买衬衫 → 知尺寸

4. 完形解题三步法（苏格拉底思路）

  1. 读懂首句，抓住背景。 开学前一天、妈妈带三男孩购物 → 人多、易走散。
  2. 逐空三问： 问逻辑（因果/转折）→ 问搭配（shop for / on sale）→ 问词义（size vs colour）。
  3. 回读全文，检查通顺。 把答案代入默读，核对语法与情节。
